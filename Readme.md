# 🤖 ITI NLP Course - Applied Learning Track

This repository contains course material, research papers, code notebooks, and slides for the **ITI Applied NLP Course**. The course aims to get you **hands-on with NLP, Transformers, LLMs, and Generative AI** through practical content and real-world research.

---

## 📌 Course Purpose

> “The purpose of this course is to get you kicking with NLP, Transformers, LLMs, and Gen AI.  
> This is an **applied course**.”

---

## 📘 Course Content

### 🔹 Code Notebooks (`code notebooks/`)
Practical Jupyter notebooks for each lecture:
- `lec1.ipynb` → Introduction to NLP
- `lec2.ipynb` → Tokenization and Embeddings
- `lec3.ipynb` → RNNs and Sequence Models
- `lec4.ipynb` → Transformers Overview
- `lec5.ipynb` → BERT and Fine-tuning
- `lec6.ipynb` → LLMs in Action
- `lec7.ipynb` → Final Applications & Projects

### 📊 Slides
- `NLP ITI - material.pdf` – Contains the visual explanation and theoretical part of the course.
